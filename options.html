Transcript Extractor Settings

Enter the HTTP POST URL from your Power Automate flow trigger. The transcript will be sent in JSON format with "Meeting Title" and "transcript" fields.

How to Setup Power Automate Integration

Step 1: Create a new Flow

  1. Go to Power Automate
  2. Create a new Instant cloud flow or Automated cloud flow
  3. Add the trigger: "When a HTTP request is received"

Step 2: Configure the HTTP Trigger

In the HTTP trigger settings:

  • Who can trigger the flow: Select "Anyone" (or "Iedereen" in Dutch)
  • Request Body JSON Schema: Paste the schema below
{
    "type": "object",
    "properties": {
        "Meeting Title": {
            "type": "string"
        },
        "transcript": {
            "type": "string"
        }
    }
}

Step 3: Copy the HTTP URL

After saving the flow, Power Automate will generate an HTTP POST URL. Copy this URL and paste it in the field above.

Step 4: Add Actions to Your Flow

Now you can use the received data in your flow:

  • Meeting Title - Contains the video title
  • transcript - Contains the full transcript text

Common actions: Send to email, save to SharePoint, send to Teams, process with AI (e.g., OpenAI GPT), etc.
